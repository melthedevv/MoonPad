# 🌙 MoonPad™
**A node-based notepad that lives inside After Effects.**
Drop in text, screenshots and videos, drag them around, and wire them together like Unreal Blueprints.

-# A Moonlit™ product · Founded by melthedev (mel)

![MoonPad inside After Effects: text notes, an image, colored nodes and wires on a dark board](https://raw.githubusercontent.com/melthedevv/MoonPad/refs/heads/main/Screenshot%202026-10-10%20195449.png)

## ✨ What it does
- 📝 Text notes, 🖼️ images and 🎬 videos on an infinite board
- 🔗 Connect anything with wires, and right-click a wire to change its color
- 🌗 Dark and light mode, custom color themes, your own background image and font
- 💾 Saves automatically for each After Effects project
- 📦 Export and import `.mnpad` files to share a whole pad

## 📥 Install (Windows)
1. Download `MoonPad.zip` and **unzip it** (don't run it from inside the zip)
2. Double-click **`install.bat`** (no admin needed)
3. Restart After Effects
4. Open **Window → Extensions → MoonPad**

Updating? Just run `install.bat` again. Your pads are kept.
-# Windows says "protected your PC"? Click **More info → Run anyway**.

## 🖱️ Controls
- **Double-click** empty space → new note
- **Ctrl+V** a screenshot, or **drag in** an image or video
- **Drag from a node's right pin** → connect it to another node (drop on empty space to make a new linked one)
- **Right-click a wire** → pick its color · **double-click** a wire → delete it
- **Drag** empty space to pan · **scroll** to zoom
- **Gear icon** (top right) → settings

## 📁 Saving and sharing
Each project gets its own pad, saved to `Documents\MoonPad`, and MoonPad remembers which pad belongs to which project.
- **File → Open pad…** open a `.mnpad`
- **File → Export a copy…** share your pad (videos are packed inside, up to about 150 MB)
- **File → Import into this pad…** merge someone else's pad into yours

🎬 Videos: MP4, WebM, MOV, M4V or OGV, up to 200 MB each. If one won't play, re-encode it as WebM or H.264 MP4.

## 🛠️ Trouble?
- Not showing in Window → Extensions? Fully close After Effects, run `install.bat` again, then reopen it.
- "Can't find the moonpad folder"? Unzip the whole download first.
